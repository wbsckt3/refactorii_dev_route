Resumen Ejecutivo

Este plan de automatización está diseñado para validar el correcto funcionamiento de una arquitectura de microservicios basada en Spring Boot, con foco en los endpoints de health check y la integración entre servicios.

Objetivos principales

  • Verificar el estado de salud de todos los microservicios
  • Automatizar las pruebas de integración entre servicios
  • Generar reportes de ejecución para análisis de calidad
  • Integrar con pipeline CI/CD para ejecución automática
Progreso general: 65%
Arquitectura del Sistema

La arquitectura consiste en múltiples microservicios Spring Boot que se comunican a través de un API Gateway y se registran en un servicio de descubrimiento.

# Ejemplo de configuración de microservicios
microservices:
  discoverer:
    port: 8761
    health: http://localhost:8761/actuator/health
  gateway:
    port: 8080
    health: http://localhost:8080/actuator/health
  keycloak:
    port: 9080
    health: http://localhost:9080/auth/health
  zipkin:
    port: 9411
    health: http://localhost:9411/health

Script de Configuración (PowerShell)

Ejecuta el siguiente script para crear la estructura de carpetas y archivos necesaria:

# setup-cypress-project.ps1
$folders = @(
  "cypress/e2e",
  "cypress/support", 
  "cypress/reports",
  "config",
  "monitoring",
  ".github/workflows"
)

foreach ($folder in $folders) {
  if (!(Test-Path -Path $folder)) {
    New-Item -ItemType Directory -Path $folder -Force | Out-Null
    Write-Host "Carpeta creada: $folder"
  }
}

$files = @(
  "cypress/e2e/system-health-check.cy.js",
  "cypress/support/commands.js", 
  "config/dev.env.js",
  "monitoring/dashboard-config.js",
  "package.json",
  ".github/workflows/system-health-check.yml"
)

foreach ($file in $files) {
  if (!(Test-Path -Path $file)) {
    New-Item -ItemType File -Path $file -Force | Out-Null
    Write-Host "Archivo creado: $file"
  }
}

Write-Host "✅ Estructura de proyecto Cypress creada exitosamente."
Configuración de Microservicios

Para habilitar los endpoints de health check en cada microservicio Spring Boot, agregar la siguiente configuración:

<!-- En pom.xml -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
    <scope>runtime</scope>
</dependency>
# En application.yml
management:
  endpoints:
    web:
      exposure:
        include: health,info
  endpoint:
    health:
      show-details: always

Comandos de Ejecución

Secuencia de comandos para ejecutar las pruebas:

# Navegar al directorio del proyecto
cd C:\ruta\de\tu\proyecto

# Instalar dependencias
npm install

# Abrir Cypress en modo interfaz gráfica (E2E Testing)
npm run test:open

# Ejecutar pruebas en modo consola (CI/CD)
npm run test:e2e

# Generar reporte HTML
npm run test:report
Monitoreo y Reportes

Los reportes se generan en la carpeta cypress/reports/html/ después de cada ejecución.

Métricas clave a monitorear:

  • Tasa de éxito de pruebas (%)
  • Tiempo promedio de ejecución
  • Detección temprana de bugs
  • ROI de automatización
Integración CI/CD

Configuración de GitHub Actions para ejecución automática:

# .github/workflows/system-health-check.yml
name: System Health Check
on:
  push:
    branches: [ feature/automation ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
    - name: Install dependencies
      run: npm install
    - name: Run E2E tests
      run: npm run test:e2e
    - name: Generate report
      run: npm run test:report
    - name: Upload report
      uses: actions/upload-artifact@v3
      with:
        name: test-report
        path: cypress/reports/html/
