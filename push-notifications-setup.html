📱 Notificaciones Push Nativas

Guía completa de configuración para RealDB

✅ ¿Qué son las Notificaciones Push?

Las notificaciones push nativas del navegador permiten enviar notificaciones a los usuarios incluso cuando la aplicación está cerrada. Funcionan en segundo plano usando Service Workers.

Ventajas:
  • Funciona sin app abierta: Notificaciones incluso cuando el navegador está cerrado
  • Nativo del navegador: No requiere apps externas (Telegram, WhatsApp)
  • Gratis: Sin límites ni costos
  • Multiplataforma: Funciona en Chrome, Firefox, Edge, Safari
  • Privacidad: El usuario controla los permisos

🔑 Paso 1: Generar Claves VAPID

Las claves VAPID son necesarias para autenticar las notificaciones push. Genera un par de claves:

cd modelos_back npx web-push generate-vapid-keys

Esto generará algo como:

Public Key: BEl62iUYgUivxIkv69yViEuiBIa40HIeF8vUvKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8 Private Key: 8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8

📝 Paso 2: Configurar Variables de Entorno

Crea o actualiza el archivo .env en modelos_back/:

# VAPID Keys para notificaciones push VAPID_PUBLIC_KEY=tu_public_key_aqui VAPID_PRIVATE_KEY=tu_private_key_aqui VAPID_EMAIL=tu-email@example.com
Ejemplo:
VAPID_PUBLIC_KEY=BEl62iUYgUivxIkv69yViEuiBIa40HIeF8vUvKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8 VAPID_PRIVATE_KEY=8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8vKX8 VAPID_EMAIL=admin@refactorii.com

📦 Paso 3: Instalar Dependencias

cd modelos_back npm install

Esto instalará web-push que es necesario para enviar notificaciones.

🚀 Paso 4: Configurar Service Worker

El Service Worker (public/sw.js) ya está creado. Solo asegúrate de que:

  1. El archivo esté en la carpeta public/ de tu proyecto
  2. El servidor sirva archivos estáticos desde public/
Si usas Vite, el Service Worker debe estar en public/sw.js y se servirá automáticamente.

🎯 Paso 5: Agregar Componente en el Perfil

Agrega el componente PushNotificationsSetup.vue en el perfil del usuario:

<!-- En AdminProfile.vue o TechnicianProfile.vue --> <template> <div> <!-- ... otros componentes ... --> <PushNotificationsSetup /> </div> </template> <script setup> import PushNotificationsSetup from '../components/PushNotificationsSetup.vue'; // ... </script>

✅ Paso 6: Probar

  1. Inicia el servidor:
    npm start
  2. Abre la aplicación en el navegador
  3. Ve al perfil del usuario y haz clic en "Activar Notificaciones"
  4. Acepta el permiso cuando el navegador lo solicite
  5. Cierra la aplicación y crea una solicitud/propuesta
  6. Deberías recibir una notificación incluso con la app cerrada

🔧 Cómo Funciona

Flujo Completo:

  1. Usuario activa notificaciones:
    • El navegador solicita permiso
    • Se registra el Service Worker
    • Se crea una suscripción push
    • La suscripción se guarda en el servidor
  2. Usuario se conecta:
    • La suscripción se envía al servidor en la autenticación del socket
    • Se guarda asociada al userId
  3. Se crea/actualiza solicitud/propuesta:
    • Si el usuario está conectado: Notificación por Socket.io
    • Si el usuario tiene suscripción push: Notificación push (incluso si está desconectado)
    • Ambas se envían siempre
  4. Usuario recibe notificación:
    • Si la app está abierta: Notificación en la app
    • Si la app está cerrada: Notificación del sistema operativo

📱 Requisitos del Navegador

  • ✅ Chrome/Edge: Totalmente soportado
  • ✅ Firefox: Totalmente soportado
  • ✅ Safari: Soportado (iOS 16.4+)
  • ⚠️ Opera: Soportado
  • ❌ Internet Explorer: No soportado

🔐 Seguridad

  • Las claves VAPID son públicas (puedes exponer la clave pública)
  • La clave privada debe mantenerse secreta (solo en el servidor)
  • Las notificaciones están encriptadas end-to-end
  • El usuario puede revocar permisos en cualquier momento

🆘 Solución de Problemas

Error: "Service Worker registration failed"

  • Verifica que public/sw.js exista
  • Verifica que el servidor sirva archivos estáticos
  • Usa HTTPS en producción (requerido para Service Workers)

Error: "VAPID keys not set"

  • Genera las claves con npx web-push generate-vapid-keys
  • Configúralas en el archivo .env

No recibo notificaciones

  1. Verifica que el usuario haya activado las notificaciones
  2. Verifica que el navegador tenga permisos
  3. Revisa la consola del navegador para errores
  4. Verifica que el Service Worker esté registrado (DevTools > Application > Service Workers)

Notificaciones solo funcionan en HTTPS

  • En desarrollo local (localhost) funciona con HTTP
  • En producción necesitas HTTPS
  • Usa un servicio como ngrok para probar en desarrollo
