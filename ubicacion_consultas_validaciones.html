@Query(value = """ WITH estados AS ( SELECT MAX(dt.id_cuerpo) AS id_detalle, dt.id_tracking FROM detalle_tracking dt GROUP BY dt.id_tracking ) SELECT DISTINCT et.numero_guia, COALESCE(s.nombre_archivo, fe.firma) AS resultado, CASE WHEN s.nombre_archivo IS NOT NULL THEN 'SOPORTE' WHEN fe.firma IS NOT NULL THEN 'FIRMA' ELSE 'DESCONOCIDO' END AS tipo FROM public.encabezado_tracking et LEFT JOIN estados ON estados.id_tracking = et.id_tracking LEFT JOIN public.detalle_tracking dt ON dt.id_cuerpo = estados.id_detalle LEFT JOIN public.soportes s ON s.id_soporte = dt.id_soporte LEFT JOIN public.firma_entregas fe ON fe.id_firma = et.id_firma WHERE et.numero_guia IN (:numerosGuia) AND (s.nombre_archivo IS NOT NULL OR fe.firma IS NOT NULL); """, nativeQuery = true) List<Object[]> obtenerNombresSoportesPorGuias(@Param("numerosGuia") List<String> numerosGuia);

6 El valor asegurado debe ser igual al valor del documento o transacción de Herinco

Consulta SQL

src/main/java/co/org/cohan/msalogistics/stone/repository/HdGuitraRepository.java
Nativa Stone (SQL Server) HERINCO
Método: obtenerValorDeclaradoPorNumerosGuia()
Líneas: 61-115
@Query(value = "SELECT " + " R.NUM_GUIA, " + " R.TIP_TRAN, " + " CASE " + " WHEN R.TIP_TRAN IN ('I','C') THEN 'COSTO_PROMEDIO' " + " WHEN R.TIP_TRAN = 'D' THEN 'PRECIO_COMERCIAL' " + " END AS TIPO_CALCULO, " + " SUM( " + " CASE " + " WHEN R.TIP_TRAN IN ('I','C') THEN " + " CONVERT(DECIMAL(20,0), Y.UNI_FACT * Z.COS_PROM) " + " WHEN R.TIP_TRAN = 'D' THEN " + " CONVERT(DECIMAL(20,0), G.VAL_PREC * G.CAN_ENTR) " + " END " + " ) AS VALOR_DECLARADO " + "FROM HD_GUITRA R WITH (NOLOCK) " + "LEFT JOIN HD_HIASP L WITH (NOLOCK) " + " ON R.TIP_TRAN IN ('I','C') " + " AND R.RMT_TRAN = L.RMT_CAPE " + " AND R.TIP_TRAN = L.TIP_PEDI " + "LEFT JOIN PE_CAPED A WITH (NOLOCK) " + " ON L.RMT_CAPE = A.RMT_CAPE " + " AND A.COD_EMPR = 1 " + "LEFT JOIN PE_CUPED Y WITH (NOLOCK) " + " ON A.COD_EMPR = Y.COD_EMPR " + " AND A.RMT_CAPE = Y.RMT_CAPE " + "LEFT JOIN IN_SAMES Z WITH (NOLOCK) " + " ON R.TIP_TRAN IN ('I','C') " + " AND Z.COD_EMPR = Y.COD_EMPR " + " AND Z.COD_BODE = Y.COD_BODE " + " AND Z.COD_PROD = Y.COD_PROD " + " AND Z.ANO_ACUM = YEAR(A.FEC_TRAN) " + " AND Z.MES_ACUM = ( " + " SELECT MAX(Z2.MES_ACUM) " + " FROM IN_SAMES Z2 WITH (NOLOCK) " + " WHERE Z2.COD_EMPR = Y.COD_EMPR " + " AND Z2.COD_BODE = Y.COD_BODE " + " AND Z2.COD_PROD = Y.COD_PROD " + " AND Z2.ANO_ACUM = YEAR(A.FEC_TRAN) " + " AND Z2.MES_ACUM <= MONTH(A.FEC_TRAN) " + " ) " + "LEFT JOIN HERINCO..DP_CAENT B WITH (NOLOCK) " + " ON R.TIP_TRAN = 'D' " + " AND R.NUM_DOCU = B.RMT_CAEN " + " AND B.ACT_ESTA <> 'B' " + "LEFT JOIN HERINCO..DP_CUENT G WITH (NOLOCK) " + " ON R.TIP_TRAN = 'D' " + " AND B.RMT_CAEN = G.RMT_CAEN " + " AND G.ACT_ESTA <> 'B' " + "WHERE R.NUM_GUIA IN :numerosGuia " + " AND R.EST_GUIA <> 'B' " + "GROUP BY R.NUM_GUIA, R.TIP_TRAN " + "ORDER BY R.NUM_GUIA", nativeQuery = true) List<Object[]> obtenerValorDeclaradoPorNumerosGuia(@Param("numerosGuia") List<String> numerosGuia);
Tablas involucradas:
  • HD_GUITRA (alias R)
  • HD_HIASP (alias L)
  • PE_CAPED (alias A)
  • PE_CUPED (alias Y)
  • IN_SAMES (alias Z, Z2)
  • HERINCO..DP_CAENT (alias B)
  • HERINCO..DP_CUENT (alias G)

  1. Validaciones 5, 7 y 8 no tienen consultas SQL directas porque se realizan en memoria comparando datos del CSV con entidades JPA cargadas previamente.
  2. Validación 2 tiene lógica especial: para tipo de transacción 'D' (Domicilio), se usa NIT fijo 900702986 sin consultar Stone.

  4. Todas las consultas nativas de Stone usan sintaxis SQL Server (WITH (NOLOCK), TOP 1, etc.).
  5. Todas las consultas nativas de PostgreSQL usan sintaxis PostgreSQL estándar.
